# Agentic AI Data Scientist

## Overview
This repository implements an **Agentic AI Data Scientist** system consisting of a FastAPI backend and a Streamlit frontend.  
The system coordinates multiple AI agents to perform data analysis, visualization, and summarization tasks.

The code and dependencies presuppose access to an **NVIDIA GPU** (e.g., Quadro RTX 8000). While limited functionality may run on CPU, GPU usage is strongly recommended for practical performance.

---

## Dependencies

### Python
Python 3.10+. All required Python packages are listed in `myenv.txt`.

### Ollama (Required)
This system uses **Ollama** to serve large language models locally.  
Ollama must be installed and running **before** starting the backend.

---

## Installing and Running Ollama

### 1. Install Ollama
On Linux:
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### 2. Verify Ollama Installation
```bash
ollama --version
```

### 3. Start the Ollama Server
```bash
ollama serve
```

### 4. In a separate terminal, pull the required models
```bash
ollama pull gpt-oss:20b
ollama pull llama3.1
```

## Installing and running the data scientist

### 5. Clone this github repo
```bash
git clone https://github.com/oln7373/AI-data-scientist
cd AI-data-scientist
```

### 6. Install requirements
```bash
pip install -r myenv.txt
```

### 7. Launch the FastAPI Backend
```bash
uvicorn backend:app --host 127.0.0.1 --port 8001 --reload
```
(The host and port may be changed if needed.)

### 8. Launch the Streamlit Frontend
```bash
streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

### 9. (OPTIONAL) Port Forwarding 
If running on a remote machine and accessing the interface locally, forward the necessary ports:
```bash
ssh -L 8501:127.0.0.1:8501 \
-L 8001:127.0.0.1:8001 \
-i ~/.ssh/<YOUR_KEY> \
<YOUR_USER>@<YOUR_MACHINE>.edu
```
(Ports and hostnames may be adjusted as needed.)

### 10. Access the Application
Assuming the default ports above, open your browser at:
```bash
http://localhost:8501/
```

## Environment Variables

This project uses environment variables for configuration (e.g., email settings).  
Sensitive information is not hard-coded in the source code.

### Setup

1. Copy the example environment file:
   ```bash
   cp env.sample .env
   ```
2. Edit the ```.env``` and provide your own values
   ```python
   EMAIL_RECIPIENT=your_email@example.com
  EMAIL_SUBJECT=Test Email from Gmail API
  EMAIL_BODY=Hello,\n\nThis is a test email.\n\nBest regards,
  ```

## Repository Structure

- **`output/`**  
  Contains all images and documents generated by the backend at runtime.  
  The backend will **not run** without this directory, as it is specified via the `IMAGE_DIR` variable in `multi_ai_agent.py`.

- **`data/`**  
  Contains datasets and documents provided as input to the agentic system.  
  Files in this directory are accessible to the backend during execution.

- **`figures/`**  
  Contains static images used by the Streamlit frontend interface.

- **`reports/`**  
  This directory appears to be automatically generated by the backend.  
  It is likely vestigial from earlier versions and is not required for current functionality.
